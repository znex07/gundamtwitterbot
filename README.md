# Game Development Studio

A WebGL and WebGPU game development studio with both 2D and 3D modes in one editor, built in Muse.

## Features

- 2D mode (orthographic, pan/zoom) and 3D mode (perspective, lit primitives, orbit/zoom) sharing one editor
- WebGL / WebGPU backend switcher with live GPU panel and WGSL compute test
- Add cubes, spheres, tori, stars, platforms and more; drag in viewport
- Inspector for position, rotation, scale, color and behaviors: spin, bounce with gravity, float, orbit, pulse, drift, patrol
- Play mode animates behaviors with timer/FPS; Stop resets
- Scene-code view, JSON export/import, project saving
- craftz.dog-inspired UI: warm charcoal, teal accents, frosted-glass blurry transparency panels, dark/cream theme toggle
- Standard / Ghibli shading toggle: banded toon shading with 4-step gradient, pale sky, warm sunlight
- Turntable toggle: slow auto-rotate like a voxel hero, pauses while dragging

## Built-in scenes and templates

- Tiny Dog — Super Deformed: tiny panel-head dog, pale yellow hoodie, backpack, black base
- Voxel Dog — Tiny Voxel: same tiny dog built from cube voxels, matte voxel finish
- Dog Character 3D: full-size dog character scene
- Ghibli Meadow: toon trees with green-gradient canopies, sun, drifting clouds (auto-enables Ghibli shading)
- Voxel Desk — Dog at Work: voxel dog at a wooden desk with teal laptop, mug, and plant
- Neon Orbit 3D
- Platformer Meadow 2D

## Notes

This branch (`game-development-studio`) holds the studio documentation and manifest. The live studio runs as a Muse web artifact (`game-development-studio`).

Original character artwork is a dog (not a pig), in light tan / pale yellow / light tan colors, tiny and super-deformed, with a smaller/flatter top head and dog muzzle.
