Game Development Studio

A WebGL and WebGPU game development studio with both 2D and 3D modes in one editor, built in Muse. Inspired by craftz.dog — frosted-glass blurry transparency, voxel 3D, and Ghibli-style toon shading.

The live studio runs as a Muse web artifact. This Pages site hosts the exported scenes, manifest, and docs. The character is a dog (not a pig): light tan fur, pale yellow hoodie, tiny super-deformed, smaller/flatter top head, dog muzzle with black nose and XX.

Features

  • 2D (orthographic) and 3D (perspective) modes, WebGL / WebGPU switcher
  • Inspector: position, rotation, scale, color, behaviors (spin, bounce, float, orbit, pulse, drift, patrol)
  • Play mode, scene-code view, JSON export/import, project saving
  • Standard / Ghibli shading toggle, Turntable auto-rotate
  • Export tab: full package download with all scenes and saved projects
